AGENDA DE ANIVERSÁRIOS

1. Extraia o ficheiro ZIP.
2. Abra AgendaDeAniversarios.sln no Visual Studio.
3. Carregue em Executar ou prima F5.

Crie uma conta com email e palavra-passe. Depois inicie sessão.
Na agenda pode pesquisar, adicionar, editar e eliminar aniversários.
Os dados são guardados só enquanto o programa está aberto.

O código utiliza Windows Forms e .NET 10. Não usa base de dados nem bibliotecas adicionais.
